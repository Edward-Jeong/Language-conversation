# 독립 코드·디자인 검토

검토일: 2026-10-22. 검토 기준은 `english_conversation_codex_final_spec_v1.md`, `DESIGN.md`, `docs/CORE_ENGINEERING_PROTOCOL_V2.md`다. 구현 담당자와 분리된 검토자가 최종 소스, 명세, 검사 결과, 390px 홈/360px 대화 화면 캡처를 직접 대조했다. 실제 iPhone과 제공자 실행은 이 검토자가 수행하지 않았다.

## 판정

**review-ready.** 현재 소스에서 확인한 보안·학습 상태·UI 결함은 수정됐고, 독립 집중 검사는 통과했다. 그러나 실제 모델의 교정 품질과 지연, iPhone 음성 왕복, 저장소 전체 필수 테스트가 수용 기준을 충족하지 못했거나 미검증이다. 전체 모바일 자동 음성 MVP 또는 merge-ready로 판정하지 않는다.

## Axis A — 동작·보안·데이터 무결성

- 서버가 현재 질문의 intent/task variant, 힌트 노출, 재시도 대상, 복습 결과와 일정을 결정한다. 클라이언트가 다른 transfer 분류를 제출하는 요청은 거부된다. 교정 중 다음 질문은 응답에서 가려지고 서버 상태에만 보류된다.
- 페어링 코드는 1회용·만료·실패 시도 제한을 적용한다. 실패 기록이 롤백되던 결함과 예측 가능한 인증 비밀 기본값은 수정됐다. 상태 변경에 Origin/CSRF, 학습 자료에 세션 소유권 검사가 있으며 제공자 URL은 loopback으로 제한된다.
- 전사 수정은 최신 답변에 한정하고 새 평가 전에 기존 상태를 보존한다. 성공 시 이전 평가·자동 카드·복습 영향을 무효화하고 새 버전으로 상태를 다시 계산한다. 중지·일시정지 뒤 늦은 생성은 서버 revision과 클라이언트 operation epoch/abort로 차단한다.
- 음성 재시도는 서버의 현재 교정 턴에 연결된다. 세션 재로드 중 교정 문맥을 다시 제공하고, 복습 음성 요청도 서버 평가를 사용한다. 가져오기는 미리보기에서 필수 필드, 관계, enum, 정수 범위, 크기 등을 검증한다. 기본 세션 삭제는 연결된 편집 표현, 캐시된 멱등 응답, 가져오기 미리보기도 정리하며 고유 전사 문구가 모든 DB TEXT 열에서 사라지는 회귀 검사가 있다.
- 음성 업로드는 STT 전에 세션 소유권과 활성 상태를 확인하고 상태 lease를 잡는다. STT 대기 전과 결과 제출 때 lease를 다시 검사하므로 일시정지·재개나 턴 변경 중 나온 늦은 전사를 버린다. 가짜 STT 호출 수를 세는 회귀 검사에서 타인·일시정지 세션은 STT를 호출하지 않았다.
- 일시정지·종료·질문 건너뛰기는 진행 중인 평가 작업에 취소 신호를 보내고 예약된 답변과 중복 요청 키를 정리한다. 건너뛰기는 기존 힌트 노출 기록을 유지하며 질문 건너뛰기와 다음 질문 이벤트를 한 번씩 기록한다. 가짜 평가 제공자를 사용한 검사가 실제 코루틴 취소와 평가 미저장을 확인했다.
- 복습은 텍스트·음성 결과에 한 가지 교정 또는 성공·평가 보류를 같은 카드에서 표시한다. 서버는 첫 답변 뒤 당일 재시도 두 번을 제한하고, 교정 예문과 선택한 다른 표현을 H3 노출로 기록한다. 다음 카드로 이동하는 조작은 결과 확인 뒤 명시적으로 제공된다.
- 상황 전이는 같은 문구가 이전 대화 또는 복습에 이미 노출됐는지 서버가 확인해 반복 문구를 새 상황 성공으로 부풀리지 않는다. 종료 요약은 저장된 답변·독립 성공·교정·다음 표현을 조회해 구성하며 답변 0개의 경우도 사실대로 표시한다. 종료된 화면에서는 녹음·재생·답변·수정 컨트롤을 숨기고 동작 경로도 비활성화한다.
- **남은 제품 수용 결함:** 실제 loopback 음성 요청은 수정된 실행 환경에서 HTTP 200·`ready`·독립 성공을 반환했으나, 합성 음성 한 턴의 서버 왕복이 32.53초(STT 2.23초)였다. 앞선 혼잡 실행은 HTTP 200·`unassessable`·약 98.9초였다. 고정 50문항 실제 모델 평가에서는 자동 휴리스틱 49/50이 통과했지만 정상 문장 1개(Q20)에 불필요한 필수 교정이 나왔고, 응답 7개는 `unassessable`이었다. 모델 직접 호출 지연은 중앙값 23.17초/p95 26.56초로 목표 3초/6초를 넘었다. 50개 모두 사람의 교정 적절성 검수가 남아 있다. 근거: `docs/evidence/real-api-audio-final.json`, `docs/evidence/real-api-audio.json`, `docs/evidence/tutor-quality-v3.summary.json`, `docs/evidence/tutor-quality-v3.jsonl` (주 실행자의 검사). 실제 iPhone의 10턴 자동 왕복, 에코, 권한·복귀·종료, 30턴 지연은 미검증이다.

## Axis B — 코드베이스 적합성

- React/Vite UI, FastAPI 학습 상태, SQLite 마이그레이션, 버전 관리한 시나리오·프롬프트·출력 스키마, loopback Ollama/whisper.cpp 어댑터가 명세의 소규모 개인 설치 경계를 따른다. 목업 모드는 명시적으로 표시하고 유료 API로 자동 전환하지 않는다.
- 서비스워커는 정적 셸만 캐시하며 `/api/` 요청은 캐시하지 않는다. 설치·모델·기기·제약 문서는 실제 실행과 미검증 범위를 구분한다.
- **제안:** `apps/api/orchestrator.py`와 `apps/api/data_service.py`의 긴 압축 문장은 향후 상태 전환·가져오기 변경의 검토 비용을 높인다. 새 기능 전에 의미별 함수 분해와 일반적인 줄바꿈을 권장한다. 현재 확인한 기능 결함으로 분류하지 않는다.

## Design Review

`DESIGN.md`가 존재하고 초록·종이색 토큰, 단일 열 대화 흐름, 명시적 상태/복구 문구, 5개 하단 메뉴, 포커스 표시, reduced-motion을 적용한다. `output/playwright/home-390-final.png`에서 한국어 제목 줄바꿈이 읽기 쉬워졌고, `output/playwright/conversation-360.png`에서 주요 컨트롤과 오류 문구가 360px 폭에 표시된다. 검토 중 발견한 작은 터치 영역과 장식 그라디언트는 수정됐다. **디자인 차단 결함 없음.** 두 캡처는 PC Chromium 증거다. iPhone 안전 영역, 키보드 표시, 텍스트 확대와 실제 보이스는 아직 검증되지 않았다.

백그라운드·오프라인 복귀는 진행 중인 서버 일시정지 요청을 기다리고 서버 상태를 다시 조회한 뒤 한 번의 복귀 조작으로 재개한다. 연속된 생명주기 알림은 같은 일시정지 요청을 재사용해 늦은 요청이 재개 상태를 뒤집는 경로를 줄였다.

활성·화면 표시·온라인 상태에서만 15초 간격 연결 확인을 보내며, 실패 뒤 명시적으로 재개하면 연결 확인을 새로 시작한다. 서버는 60초 연결 만료를 15초 간격으로 검사해 세션을 일시정지하고 평가·음성 입력 작업을 취소한다. 동시 음성 입력 두 개의 취소와 후속 튜터 평가 미호출을 검증했다. 오디오 임시 파일은 DB 옆 전용 폴더에서 접두사와 5분 TTL로 제한해 정리한다. 실제 모바일에서의 잠금·네트워크 전환은 아직 검증되지 않았다.

## 실제 수행·남은 검증

- 독립 실행: `.runtime/lockvenv/Scripts/python.exe -m pytest tests/test_learning_flow.py tests/test_api_security.py tests/test_product_boundaries.py -q --tb=short --basetemp .pytest-review-finalcore` → **33 passed, Starlette/httpx 경고 1개**. 프로젝트 로컬 임시 디렉터리를 사용했다.
- 독립 실행: `cd apps/web; npm run build; npm test -- --run` → **빌드 성공, 13 passed**.
- 주 실행자 기록: 전체 저장소 pytest는 **36 passed, 5 failed, 25 subtests**. 실패 5개는 기존 템플릿 검사에서 WSL `/bin/bash` 부재 및 Windows 심볼릭링크 권한 오류다. 이를 통과로 간주하지 않는다.
- 주 실행자 기록: PC loopback HTTPS/CA에서 미인증 401, Secure/HttpOnly/SameSite 쿠키, Origin 403, 페어링 코드 재사용 401을 확인했다 (`docs/evidence/https-probe.json`).
- 주 실행자 기록: 취약점 보고가 있던 Python 패키지 핀을 갱신한 뒤 분리된 감사 환경에서 알려진 취약점이 보고되지 않았다 (`docs/evidence/pip-audit-after.json`). npm 감사는 레지스트리 요청 시간 초과로 결과를 얻지 못했다 (`docs/evidence/npm-audit.json`); 이를 통과로 간주하지 않는다.
- 50개 모델 교정의 사람 검수, 실제 iPhone A01–A16 관련 항목, 다음날·1주 지연 복습과 학습 효과는 미수행이다. 목업·합성 음성·PC 브라우저 결과로 대체할 수 없다.

주 실행자 최종 원자료 추가: `docs/evidence/real-api-audio-final-auto.json`에서 자동 언어 감지 설정의 합성 음성 한 턴은 전사·평가 ready 성공,43.85초(STT3.235초)였다. 주 실행자는 당시 앱 의존성 설치·개발 검사가 병행됐음을 기록했다. 이전 영어 고정 요청32.53초를 대체·삭제하지 않고 두 조건을 구별한다. 어느 결과도 실제 iPhone 전체 지연이나 지연 목표 통과를 입증하지 못한다.

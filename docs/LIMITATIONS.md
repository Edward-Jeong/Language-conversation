# 알려진 제약

2026-10-22. 이 개발 버전은 실제 모바일 자동 음성 MVP 검수 완료 상태가 아니다. 미구현/미검증을 기능 축소 승인으로 해석하지 않는다.

- 본 PC의 gemma3:4b 직접 호출만 웜8.3~11.4초였고, 최종 구조화 튜터50표본은 중앙23.17초/p9526.56초였고, 실제 서버 음성 한 턴은 영어 고정32.53초/자동 감지 최종43.85초였다. 초기 목표 중앙3초/p95 6초를 달성하지 못했다. 정확한 기기 전체 지연30턴 실험 전이다.
- iPhone Safari·홈 화면의 마이크/MIME·영어 voice·실제 재생·10턴 자동 왕복·스피커/이어폰 에코·잠금/전화/복귀는 미검증이다. PC Chromium의 화면 검사는 대체가 아니다.
- actual STT는 개인정보 없는 합성 음성 한 문장3회로만 확인했다. 학습자 발음·잡음·다국어 정확도를 보장하지 않는다.
- 모델 교정은 오류 후보이며 평가 보류가 발생할 수 있다. 50개 고정 표본을 실제 모델로 전부 실행했으며 자동 휴리스틱49/50(정상문장 오교정1개)이었다. 기대 기준과 제안 수정의 사람 검수는 대기 중이다. 교정/표현 품질을 일반 정확도나 공인 점수로 표시하지 않는다.
- PC가 켜져 있고 같은 LAN에 있어야 한다. 외부 이동/공개 접속·동기화는 지원하지 않는다. 무료는 회당 외부 유료 API가 없는 경로를 뜻하며 기존 PC의 전력/네트워크/저장 비용이 없다는 뜻은 아니다.
- Browser SpeechSynthesis voice의 기기/외부 처리 방식은 기기별 검증이 필요하다. SpeechRecognition API나 유료 TTS를 필수 의존성으로 사용하지 않는다.
- 다음날·약1주 뒤 처음 보는 상황의 복습 실험은 미수행이다. 자동 테스트와 학습 효과는 별개다.
- 테스트 목업은 UI와 상태 검증용이며 실제 AI로 위장하지 않는다. 기기 증거·모델 통합·자동 로직 검사를 TEST_REPORT에서 구분한다.
- 개인 프로필1개다. LAN도 페어링이 필요하다. 계정·결제·카메라·화면 공유·네이티브 앱·정밀 발음 점수는 구현하지 않는다.
- 기존 Luna 템플릿 전체 테스트의 Windows WSL Bash/심볼릭링크 권한 실패5개는 앱 검증과 별개로 남아 있다. 시스템 설정을 바꾸거나 테스트를 삭제/완화하지 않았다.

구체적 잔여 구현·검수 현황은 TEST_REPORT.md와 INDEPENDENT_REVIEW.md를 기준으로 한다. 현재 상태는 review-ready이며 공개 배포·병합 준비 완료가 아니다.


운영 범위는 단일 API 프로세스다. 여러 worker/여러 PC로 확장하는 구성은 검증하지 않았다. 명시적 중지·lease 만료 시 서버의 대기 작업과 HTTP 연결을 취소하지만, Ollama/whisper.cpp 네이티브 엔진에서 이미 시작한 연산이 즉시 끝나는지는 별도 실측이 필요하다. 실기기 네트워크 단절과 OS 중지 조합은 DEVICE_CHECKLIST의 미검증 항목으로 남는다.


일부 서버 진단 오류는 영문 문구로 표시될 수 있습니다. 일반 학습 안내·교정 설명은 한국어이며, 이 진단 문구의 추가 현지화는 남아 있습니다.

## 추가 구현 결정

초기 버전의 실제 표시 질문은 시나리오의 검수 가능한 콘텐츠에서 서버가 선택한다. LLM의 next_question 후보는 참고 결과로 보존하되, intent 매핑·새 상황·한국어 번역의 일관성을 위해 표시 단계의 권위를 주지 않는다. 이는 실제 모델 평가를 고정 답변으로 대체하는 설정이 아니다. 학습자의 문장은 실제 로컬 모델이 의미와 오류 후보를 평가하며 모범 문장 일치 여부로 채점하지 않는다.

음성/요청 취소·노출·멱등 상태는 단일 API 프로세스를 전제로 구현한다. 연결 heartbeat와 만료 시 일시정지는 사용자 모르게 자동 재개하지 않는 쪽으로 결정했다. 정상 종료 요약은 저장된 답변/교정에서 결정적으로 계산하므로 별도 모델 요약 실패 때문에 기록을 잃지 않는다.

Pages 웹/동일 출처 API 프록시와 PC 모델 실행을 연결한다. 기존 개인 DB와 분리한 external-test DB를 사용한다. 도메인이 없어 무료 Quick Tunnel을 선택했으며 PC 종료/터널 재시작 시 연결이 끊기거나 주소가 바뀐다. 세션 인증 외에 Pages→PC 비밀 헤더를 추가한다.

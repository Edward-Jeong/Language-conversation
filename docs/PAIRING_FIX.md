# 기기 연결 오류 복구 (2026-10-22)

서버 로그에서 잘못되거나 만료된 코드401 뒤 페어링 시도 제한429가 반복된 것을 확인했다. 기존 오류는 화면 상단 공통 알림에만 나와 모바일 키보드/스크롤 상태에서 입력창 근처에 안내가 보이지 않을 수 있었다. 실제 iPhone 화면을 직접 관찰한 것은 아니다.

- 연결 오류를 입력창 바로 아래·버튼 위에 한국어로 표시하고 실패 후 해당 안내를 화면에 보이도록 스크롤한다. 접근성 alert와 입력창 오류 연결을 적용한다.
- 코드 오류/만료·사용, 10분 시도 제한, 입력 형식, 응답 지연을 구분한다. 페어링 요청은15초에 중단하고 재시도 안내를 표시한다. 중복 탭 요청을 막는다.
- 실패 회귀 검사2개가 수정 전 실패하는 것을 확인한 뒤 구현했다. 웹 검사16개·프로덕션빌드 통과. PC Chromium390×660에서429를 주입해 입력창 옆 한국어 안내와 버튼 앞 배치/스크롤을 확인했다. `output/playwright/pairing-rate-limit-390.png`는 모의429 UI검사이며 실제iPhone 검사가 아니다.
- 외부 테스트 DB의 실패 시도 기록을 운영자가1회 정리해 사용자의 재시도를 복구한다. 서버의5회/10분 시도 제한은 유지한다. 학습 기록/인증 비밀은 변경하지 않는다.
